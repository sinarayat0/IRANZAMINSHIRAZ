# ایران زمین شیراز

وب‌سایت فارسی و راست‌چین گروه سرمایه‌گذاری و توسعه املاک ایران زمین شیراز.

## اجرای محلی
1. Node.js نسخه 18 یا بالاتر را نصب کنید.
2. در پوشه پروژه دستور `npm start` را اجرا کنید.
3. در مرورگر آدرس `http://localhost:3000` را باز کنید.

## استقرار
این پروژه یک وب‌سرور ساده Node.js دارد و روی سرویس‌های میزبانی پشتیبان Node.js قابل اجراست. برای انتشار عمومی، پروژه باید روی هاست/سرور مستقر شود و دامنه به آن متصل گردد.

## اطلاعات قابل ویرایش
- شماره تماس، واتساپ و تلگرام در `public/index.html` تعریف شده‌اند.
- فعلاً ملک نمونه‌ای نمایش داده نمی‌شود.
- بخش مدیریت، ورود کارکنان و پرداخت آنلاین در این نسخه پیاده‌سازی نشده‌اند و برای مرحله بعدی توسعه در نظر گرفته می‌شوند.
